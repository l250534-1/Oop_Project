# Academic Office Automation System

A terminal-based University Management System developed in C++
as an Object-Oriented Programming project.
The system automates common academic office operations such as student management, course registration,
grading, scheduling, and teacher feedback using a file-based database.

## Features

### Student Management
- Regular Students
- Scholarship Students
- Exchange Students
- CRUD operations

### Teacher Management
- Teacher profiles
- Feedback and ratings
- Assigned courses

### Course Management
- Core Courses
- Elective Courses
- Lab Courses

### Assessment System
- Exams
- Quizzes
- Assignments
- Configurable weightages

### Registration System
- Capacity checking
- Time conflict detection
- Course enrollment

### Scheduler
- Venue allocation
- Exam scheduling
- Conflict resolution

### Database
- File-based persistence
- Student records
- Teacher records
- Courses
- Venues
- Sections
- Assessments
